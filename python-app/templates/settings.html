This is who the agent writes as. The name, brand, resume and portfolio below end up inside the drafts it produces, and that is the difference between an email that sounds like you and one that sounds like a mail merge.

Profile

What you sell, and to whom. The scorer compares every business against this, so the narrower it is the better the shortlist. e.g. "web design for restaurants".

Resume

A .pdf, .docx, .txt or .md file. Only the extracted text is kept, the file itself is never stored, and that text is given to the model when it drafts.

Portfolio

Give a URL and the server fetches and stores its text, so the model can reference your actual work instead of inventing examples.

Optional. Leave a field blank to keep the current value. Keys are encrypted at rest and are never shown again. You will only ever see whether one is set.
